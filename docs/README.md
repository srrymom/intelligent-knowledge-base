# Документация проекта

Эта папка содержит актуальные документы для превращения прототипа в ВКР.

## Основные документы

- [Концепция дипломного проекта](diploma_project.md) - общая постановка, цель, объект, предмет, границы и честный статус старых отчетов.
- [Установка и запуск проекта](setup_run_guide.md) - как поставить окружения, зависимости, Ollama/FFmpeg и запустить Gradio UI.
- [План исследовательской части](research_plan.md) - исследовательские вопросы, гипотезы, методы сравнения, корпус и ожидаемые таблицы.
- [Протокол оценки качества](evaluation_protocol.md) - правила оценки конспектов, разметка, метрики, экспертная рубрика и требования к честности.
- [План разработки прототипа](development_plan.md) - текущее состояние системы, этапы доведения до защиты и приоритеты.
- [Gap-анализ проекта](project_gap_analysis.md) - расхождения между курсовой, спринтом и текущей реализацией.
- [Gap-анализ требований и библиотек](requirements_libraries_gap.md) - различия между заявленными требованиями, стеком и фактическими зависимостями.
- [Диаграмма архитектуры](architecture.md) - схема компонентов текущего программного прототипа.

## Как использовать

`diploma_project.md` считать главным источником правды по идее ВКР. Старые файлы из `.workbench/` использовать как черновики и справочники, но не как финальные результаты экспериментов.

`research_plan.md` и `evaluation_protocol.md` нужны для исследовательской главы и экспериментального раздела. `development_plan.md` нужен для практической части и планирования задач в коде.
