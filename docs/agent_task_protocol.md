# Протокол журналирования задач для агентов

Этот файл предназначен для агентов, которые работают над проектом в отдельных чатах.

Цель: после каждой задачи оставлять короткий технический журнал, из которого потом легко собрать отчет о проделанной работе.

Журнал ведется свободно, но по фактам. Лучший формат:

```text
Была проблема: ...
Сделали: ...
Возникла проблема: ...
Сделали: ...
Проверили: ...
Итог: ...
```

Не нужен длинный дневник, подробные рассуждения и большие логи терминала.

## Папка для журналов

Все журналы задач хранить отдельно:

```text
docs/work_logs/
```

Имя файла:

```text
YYYY-MM-DD_short-task-name.md
```

Примеры:

```text
docs/work_logs/2026-05-24-fix-text-pipeline.md
docs/work_logs/2026-05-24-check-rag.md
docs/work_logs/2026-05-24-video-upload-audit.md
```

Если папки `docs/work_logs/` нет, агент должен создать ее.

## Как вести журнал

1. В начале задачи создать файл в `docs/work_logs/`.
2. Записать исходную проблему простым языком.
3. По мере работы добавлять блоки `Проблема` и `Сделано` можно и другие если логично например варианты решения и тд.
4. В конце записать проверки, итог и что осталось.
5. Отдельно добавить короткую секцию `Для отчета`.
